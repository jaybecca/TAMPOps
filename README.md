# TAMPOps

Premium static portfolio for TAMPOps — web development, AWS cloud solutions, DevSecOps, CI/CD and cybersecurity.

## Structure
- `index.html` — main portfolio
- `blog.html` — 50-post blog index
- `blog/` — 50 individual article pages
- `404.html` — production 404 page
- `.github/workflows/ci.yml` — HTML, sitemap and deployment-file validation
- `Dockerfile` / `nginx.conf` — container deployment
- `deployment.yaml` / `service.yaml` — Kubernetes manifests
- `site.webmanifest` / `robots.txt` / `sitemap.xml` — web/SEO metadata
